
Sistema de Gestão Clínica — Desafio Final Back-End

Aplicação web desenvolvida como atividade final da disciplina de Desenvolvimento Back-End (TSIaD - Semestre 4) para gerenciamento de pacientes, exames e consultas médicas.

Funcionalidades:

Dashboard:** Tela inicial com visão geral do sistema (`/`).
Pacientes:** Cadastro e gerenciamento de pacientes (`/pacientes`).
Exames:** Registro e controle de exames (`/exames`).
Consultas:** Agendamento e acompanhamento de consultas (`/consultas`).

Tecnologias Utilizadas:

Node.js & Express
Template Engine:** EJS
Banco de Dados:** MongoDB
